# Style personnages & monstres — v2 (références utilisateur du 2026-11-13, 32 captures)

Étude de style uniquement : personnages, monstres et histoires restent **originaux** (CLAUDE.md règle 3). Décors : inchangés (validés).

## Humains (cartes 2D)
- **Trait** : un seul contour noir (#141418), épais et constant (~3-4 % du diamètre de la tête), bouts arrondis, aucun trait intérieur
  sauf les plis de vêtement indispensables (bord de capuche, poche). Pas d'ombre propre sur les personnages ; la lumière vient de la scène.
- **Tête** : cercle parfait, blanc nacré (#f3f3f3 → bord #cfd0d6), cou blanc minuscule. Pas d'oreilles ni de nez.
- **Visage** : 2 petits ovales noirs pleins, verticaux, écartés, placés sous le milieu ; bouche = tiret minuscule / petit sourire / « o ».
  De profil : 1 œil + bouche. Cernes violets en croissant (fatigue). Aucun sourcil sauf colère/peur forte.
- **Cheveux** : aplat brun très foncé (#3a2c26) ou noir, casque / frange qui cache un œil / pics sur le dessus ; même contour.
- **Corps** : torse rectangle aux coins arrondis (vêtement en aplat : rouge brique #c4523e, gris clair #e4e5ea…), boutons = petits ronds
  gris ; bras = tubes de largeur constante, mains = ronds blancs ; jambes longues et fines (jean bleu-gris #4a5066), pieds = petits ovales
  beige clair (#e8e2d0). Tête ≈ 1/4 de la hauteur (adulte), plus grosse chez l'enfant.
- **Poses** : course (jambes en ciseaux, bras tendus), bras tendu vers l'autre, objet tenu à deux mains, regard de côté.

## Monstres (géants pâles)
- **Volume 3D façon cel-shading** : facettes nettes, **2 tons** seulement — clair blanc-lavande (#e9eaf7) et ombre bleu-violet (#8f93c9),
  frontière d'ombre franche (souvent une bande verticale), reflets lumineux sur l'arête ; contour fin sombre, aucun trait intérieur.
- **Silhouette** : petite tête en œuf sur un très long cou, épaules tombantes, torse long, bassin marqué, jambes fines, **bras démesurés**
  (jusqu'aux genoux ou plus), coude anguleux, mains anguleuses à 3-4 longs doigts.
- **Visage** : 2 petits points noirs + petite bouche « o » ; marques noires griffonnées sur le front (blessure, colère) ; débris qui s'en détachent.
- **Échelle** : ils dominent les immeubles ; plans en contre-plongée ; un doigt géant peut traverser un mur.
- Lumières : source dorée chaude dans leur main ou sur eux (halo + éclat), le reste froid.

## Mouvement permanent (rétention)
Dans **chaque plan** quelque chose bouge : faisceau de lampe qui balaie / scintille, ampoule suspendue qui oscille, poussières qui flottent,
fissure qui progresse, feuille qui frémit, débris qui tombent, clignements, regard qui tourne, main qui tremble, respiration, bouche qui s'ouvre.
